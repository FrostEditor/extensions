提交你的扩展

把你写好的扩展分享到 FrostEditor 扩展库，让所有人都能在编辑器里一键添加。

提交流程（3 步）

  1. 准备文件

    你需要准备两个文件：

    • 扩展代码：一个 .js 文件（标准的 TurboWarp/Scratch 扩展格式，末尾调用 Scratch.extensions.register(...)）。
    • 封面图（可选但强烈建议）：一张 png / jpg 图片，比例 2:1（推荐 600×300 或更大），会显示在扩展卡片上。不传则使用默认封面。

  2. 新建议题（Issue）并按格式填写

    在 仓库的 Issues 页面新建一个议题， 正文按下面的格式填写扩展信息，然后把 .js 文件和封面图直接拖进正文作为附件上传： 

    扩展名称：千絮模糊
作者：QXBurry
版本号：1.0.0
简介：为你的角色添加模糊效果，搭配图片扩展使用更佳

    一行一个字段，不需要空行。写完确认附件链接已经出现在正文里，再点「Submit new issue」。

  3. 等待审核

    管理员会对扩展代码做安全审查。审查通过后关闭议题，系统会自动把扩展同步到扩展库并重新构建站点， 几分钟后你的扩展就会出现在首页和编辑器的「添加扩展」菜单中。

字段说明

字段 必填 说明
扩展名称 是 显示在卡片上的名称。也可以写作「名称」。
作者 否 只写人名即可。附带的链接会被自动删除（如 张三 <https://…> 或 [张三](https://…) 最终都只保留「张三」）。
版本号 否 如 1.0.0。也可以写作「版本」，冒号可省略。
简介 否 一句话介绍，显示在卡片上。请写在一行内（多行只取第一行）。也可以写作「描述」。

中文冒号 ： 和英文冒号 : 都可以。

注意事项

议题正文是唯一的信息来源
.js 文件里自带的 // 头注释（Name / By / Description 等）会被整体覆盖， 卡片最终显示的名称、作者、简介完全以议题正文为准。
  • 安全要求：扩展在编辑器中以「无沙箱」方式运行，权限很高。禁止包含恶意代码、窃取数据、挖矿、混淆到无法审查的代码。无法完成审查的扩展会被拒绝。
  • 许可协议：提交即表示你同意扩展以 MIT 协议收录进本仓库。请勿提交你没有权利分享的代码。
  • 重复提交：与已有扩展功能相同的重复提交可能被合并或拒绝。

如何更新已收录的扩展

重新打开（Reopen）你当初提交的同一个议题，替换正文里的附件、更新字段内容， 然后由管理员再次关闭——系统会识别出这是同一个议题，覆盖更新原扩展而不是新建一个副本。

如何下架扩展

在原议题下留言说明希望下架，或新建议题说明理由。管理员会将扩展从列表移除 （若已有作品在使用该扩展，一般只从首页下架、保留文件，避免破坏现有作品）。

常见问题

关闭议题后多久生效？

同步通常在 1 分钟内完成，站点重新构建需要几分钟。清一下浏览器缓存或使用无痕窗口即可看到最新内容。

封面图没显示？

确认图片是拖拽上传到议题正文中的（正文里能看到图片预览），且为 png/jpg 格式。如果仍有问题，在议题下留言联系管理员。

我不会写扩展，去哪里学？

参考 TurboWarp 扩展开发文档——FrostEditor 与 TurboWarp 扩展格式完全兼容。
